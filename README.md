Digital Chaos Score
About the Project
Digital Chaos Score is a simple Python project that calculates a score based on the changes between numbers entered by the user.

The program calculates the score, displays a status, and saves the result in a text file.

Features
Calculate a chaos score from a list of numbers
Classify the result as Calm, Moderate, or Chaotic
Save the result to a text file
Handle invalid user input
Allow multiple calculations in one session
Exit the program by typing exit
Technologies
Python
Functions and Loops
File Handling
Exception Handling
How It Works
The user enters numbers separated by spaces.
The program calculates the differences between consecutive numbers.
The program calculates the chaos score.
The score is interpreted as Calm, Moderate, or Chaotic.
The result is displayed in the terminal.
The result is saved to chaos_result.txt.
How to Run
Install Python.

Download or clone this repository.

Open the project folder in a terminal.

Run the following command:

python main.py
Enter at least two numbers separated by spaces.

Type exit to close the program.

Example
Input:

10 20 30 40
Output:

Chaos Score: 100.0
Status: Chaotic
Result saved successfully.
